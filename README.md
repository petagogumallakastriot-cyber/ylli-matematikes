## Render Free + Neon Free

Platformë mësimore matematike për fëmijë, me hyrje pseudonim + PIN dhe
gjuhë SQ / EN / GR / IT.

Udhëzimet e instalimit: [deployment/render/README-SQ.md](deployment/render/README-SQ.md).

Ky kod nuk përmban profile, progres apo sekrete. Databaza Neon konfigurohet
veçmas; kodi në GitHub nuk do të thotë që faqja është publikuar në Render.

Mos ngarko `.env`, adresa databaze me fjalëkalim, kopje databaze apo të dhëna fëmijësh.
